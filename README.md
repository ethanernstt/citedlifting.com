# citedlifting.com

The public site for Cited: landing page, privacy policy and support page.
Static HTML, no build step, served by GitHub Pages at https://citedlifting.com.

`privacy/index.html` is generated from `docs/privacy-policy.md` in the app
repository (`sbl-app`): edit the policy there, then run `node render-privacy.mjs`
here and commit. Do not edit the HTML by hand.
